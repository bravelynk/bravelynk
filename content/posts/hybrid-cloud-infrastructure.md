Some organizations are hesitant to move entirely to the cloud due to local database compliance, data sovereignty, or latency requirements. For these businesses, a hybrid cloud infrastructure offers the perfect compromise.

## Designing Hybrid Architectures

- **On-premise Databases**: Keep highly sensitive customer records stored locally on physical office servers equipped with safeguards that [prevent data loss during frequent power outages](/blog/preventing-data-loss-in-power-outages).
- **Cloud-based Web Apps**: Deploy customer-facing portals on high-speed cloud edge networks, following best practices for [scaling Next.js applications](/blog/scaling-nextjs-applications).
- **Secure Gateways**: Link the two environments using encrypted VPN tunnels, as described in our recommendations for [setting up a secure office network](/blog/setting-up-office-network-securely).

Hybrid setups balance local compliance needs with global cloud performance.
